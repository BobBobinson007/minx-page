# Minx Server – Daten-Seite

Vorbereitung für eine eigene GitHub-Page zum Minx Minecraft-Server. Die Website selbst kommt später; dieses Repository enthält jetzt schon die Ordnerstruktur, die Schnittstelle für Daten und einen Ordner für Bilder.

## Aufbau

- **daten/** – hier landen die automatisch übertragenen Serverdaten (Spielerdaten, Statistiken) als JSON-Dateien
- **galerie/** – hier liegen die Bilder, die später auf der Seite angezeigt werden
- **SCHNITTSTELLE.md** – Dokumentation, wie Daten sicher vom Server hierher gelangen

## Bildergalerie

Bilder einfach in den Ordner `galerie/` legen und wie gewohnt einchecken. Sinnvoll ist eine Benennung mit Datum, zum Beispiel `2026-11-16-baustelle.png`. Wer die Bilder hochlädt, bestimmt damit auch, was später auf der Seite sichtbar wird – der Upload geschieht bewusst von Hand.
